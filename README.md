## 📖 Overview

The Bar Crawl Game is a web-based application designed to help organize and manage pub crawls. Whether you're planning a night out with friends or organizing a large group event, this application provides an interactive way to:

- Track which bars you've visited
- Manage your bar crawl route
- Keep score and have fun challenges
- Share the experience with your group

## ✨ Features

- **Interactive Web Interface** - Easy-to-use HTML-based application
- **Bar Selection** - Choose and track bars from your crawl
- **Visit Tracking** - Mark bars as visited and keep a history
- **Group Management** - Organize multiple participants
- **Responsive Design** - Works on desktop and mobile devices
- **Fun & Engaging** - Challenges and leaderboards to keep things exciting

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional installations required!

### Installation

1. Clone the repository:
```bash
git clone https://github.com/mathisbraud2006-jpg/bar_crawl.git
cd bar_crawl
```

2. Open the application:
   - Simply open `index.html` in your web browser
   - Or use a local server:
     ```bash
     python -m http.server 8000
     # or
     npx http-server
     ```

3. Navigate to `http://localhost:8000` in your browser

## 🎮 How to Use

1. **Start a Crawl** - Create a new pub crawl event
2. **Add Participants** - Invite friends and add them to the game
3. **Add Bars** - Create a list of bars to visit
4. **Track Visits** - Mark bars as visited as you go
5. **Check Leaderboard** - See who's visited the most bars
6. **Have Fun** - Enjoy your night out!
